# Project O2: Cultural Origami Catalog & Taxonomic Registry

This registry provides a complete taxonomic specification of all **63 verified origami models** across 9 cultural collections supported by **Project O2**.

Every kit in this catalog conforms to the standardized `OrigamiKit` interface, featuring validated 1-based continuous step sequences, Yoshizawa-Randlett vector notation, 3D parametric vertex synthesis, and MIT FOLD v1.1 compatibility.
