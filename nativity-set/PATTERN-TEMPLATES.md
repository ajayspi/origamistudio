## Detailed Fold Patterns

### Angel Wings - Layered Construction

**Materials**: 2-3 small squares (2-2.5") of pearlescent white

1. **Wing Base Layer**: Fold each 2.25" square into a kite/diamond shape, elongate
2. **Feather Layers**: Take smaller triangles, fold edges repeatedly to create feather points
3. **Assembly**: Layer 3-4 feather elements per wing, offset slightly
4. **Attachment**: Don't glue flat - attach at angle to create 3D curve
5. **Shape**: Curve wings upward in an arc

### Wise Man Crown/Turban - Layered Rings

For Melchior (imperial purple, 5"):

1. **Base Ring**: Create a thick band
2. **Layer 2**: Pleat a strip and wrap, offset
3. **Layer 3**: Add smaller pleated band on top
4. **Final Layer**: Create points or jewels with gold foil
5. **Attachment**: Build up, don't just fold from the figure - creates monumentality

### Mary Veil - Draped Layer

Separate element from 2.5" square:

1. Fold into triangle
2. Create soft pleats along one edge
3. Drape over head and shoulders
4. Don't pull tight - let it flow
5. Secure subtly at back

### Robe Pleating Technique

For flowing robes (Mary, Wise Men):

1. **Create base**: Form the body cone/shape
2. **Mark pleats**: Along the bottom edge, create accordion pleats of 2-3mm
3. **Vary size**: Make pleats slightly different sizes for organic look
4. **Radiate**: Pleat outward, not all same direction
5. **Shape**: After pleating, gently curve the whole robe
6. **Layer**: For extra fullness, add a separate pleated overlay

## Color Placement Strategy

Create visual harmony through intentional color use:

- **Warm colors** (burgundy, crimson) draw attention - use for Joseph, Balthazar
- **Cool jewel tones** (royal blue, purple, emerald) create richness
- **Neutrals** (cream, brown) ground the scene
- **Gold** appears sparingly on precious elements (gifts, crown, star, trim)
- **Create contrast**: Deep colors against light, jewel tones against browns

## Advanced Shaping Tips

1. **Wet shaping**: Very lightly dampen fingers and gently curve paper (use sparingly with thin paper)
2. **Reverse folds**: Create sharp angles or tucked forms
3. **Petal folds**: For flower-like elements or decorative details
4. **Squash folds**: Add volume to rounded forms
5. **Inside reverse folds**: Create recessed details

## Material Notes

- **Foil paper**: Hard to fold, use for small details only (star, trim accents). Score lightly or use pre-creased
- **Kraft paper**: Great for stable, has texture, holds shape well
- **Iridescent/pearl paper**: Perfect for angel, catches light beautifully
- **Jewel-toned origami paper**: Best for figures - has color on both sides usually
- **Avoid**: Very thin tissue paper (won't hold 3D shape)

## Troubleshooting

| Issue | Solution |
|---|---|
| Figures won't stand | Widen base, add tab, or create internal support |
| Robes look flat | Add pleats, separate layers, curve gently |
| Stable collapses | Angle walls inward for stability, add base tabs |
| Wise Men look same | Vary poses, headdresses, heights completely |
| Scene looks flat | Layer at different depths, vary heights of figures |
| Foil tears | Use larger pieces, fold gently, avoid sharp creases |
