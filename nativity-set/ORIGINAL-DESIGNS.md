# Original Multicolored 3D Architectural Nativity Set

A completely original design approach - not just placing figures in a row, but building a three-dimensional architectural scene with depth, layering, and unique folded forms.

## Design Philosophy

- **Architectural**: Build a proper stable with depth, arches, and layers rather than just a box
- **Sculptural**: Create figures with actual 3D forms - draped robes with volume, distinct poses
- **Multicolored**: Rich royal palette with intentional color blocking
- **Unique**: Original fold patterns, not copied from existing tutorials
- **Cohesive**: All pieces designed to work together as one unified scene

## Architectural Stable Design (Original)

Instead of a simple box, build a three-dimensional structure with:

### Materials
- 2-3 sheets of 6" brown kraft paper
- 1 sheet of darker brown for roof
- Gold foil strips for trim (optional)

### Construction Concept
1. **Back Wall** - Create a larger rectangular form with angled top, slightly recessed
2. **Side Walls** - Build angled walls creating depth, not just square box
3. **Manger/Niche** - Create a recessed alcove in the center-back for Holy Family
4. **Roof** - Layered thatch-like overlapping forms, angled for dimension
5. **Entryway** - Open front with depth, creating shadow/play of light
6. **Ground Layer** - Slightly elevated platform with textured surface

This creates actual architectural depth - figures can be positioned at different depths in the scene.

## Construction Philosophy

1. **Build in layers** - Create forms with multiple layers of paper for thickness and shadow
2. **Think in 3D** - Don't just fold flat, create actual volume through pleating and shaping
3. **Architectural precision** - Use crisp folds to create structure like a model building
4. **Color blocking** - Let each color create impact, use gold as accent not everywhere
5. **Depth of field** - Position pieces at different levels/depths in the stable
6. **Unique forms** - Develop original fold sequences for each piece
