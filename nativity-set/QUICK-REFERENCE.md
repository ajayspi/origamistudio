# Quick Reference Card - Origami Nativity Set

## Paper Colors
- Stable: Brown/Kraft (6")
- Mary: Light Blue (3")
- Joseph: Brown/Olive (4")  
- Baby Jesus: White/Cream (1.5-2")
- Shepherd: Tan/Brown (3-4")
- Wise Men: Purple/Red/Gold (4" each)
- Sheep: White/Cream (2-3")
- Donkey/Ox: Grey/Brown (3")
- Angel: White/Cream (3")
- Star: Gold/Foil (3-4")
